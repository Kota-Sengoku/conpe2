# No Shorts Tube

YouTube の「おすすめ」「検索」からショート動画（Shorts）を取り除いて表示する、個人用の静的サイトです。
サーバーは不要で、HTML/CSS/JS だけで動きます。APIキーや登録チャンネルはブラウザの `localStorage` にのみ保存され、外部には送信されません。

## できること

- **ホーム（おすすめ代わり）**: 自分で登録したチャンネルの新着動画を、公開日順にまとめて表示します。
- **検索**: キーワード検索の結果からショート動画を除いた一覧を表示します。
- **ショート判定は2モードから選択可能**（設定パネル）
  - `動画の長さで判定`: 60秒以下の動画を除外します。高速でAPI消費量も少ないですが、60秒を超えるショート（最近は最大3分まで存在）は除外できません。
  - `/shorts/ URLで厳密判定`: 各動画について `https://www.youtube.com/shorts/{videoId}` が実在するかを個別に確認します。より正確ですが、動画数が多いと時間がかかります。
- クリックした動画はモーダル内の埋め込みプレーヤーで再生され、YouTube本体に移動せずに視聴できます。

## 使い方

1. `index.html` をブラウザで直接開くか、下記のホスティング方法でURLを発行してアクセスします。
2. 右上の「⚙ 設定」を開き、YouTube Data API v3 のAPIキーを入力して保存します。
   - APIキーの取得方法: [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com) で「YouTube Data API v3」を有効化 → 「認証情報」からAPIキーを作成。無料枠は1日あたり10,000 quotaで、個人利用であれば十分な量です。
3. 同じ設定パネルの「チャンネルを登録」から、見たいチャンネルをチャンネル名・`@ハンドル`・チャンネルURL・チャンネルIDのいずれかで追加します。
4. 「ホーム」タブに、登録チャンネルの新着（ショート除外済み）が表示されます。
5. 「検索」タブでキーワード検索も同様にショート除外した状態で使えます。

## ホスティング方法（推奨: GitHub Pages）

このリポジトリの `youtube-no-shorts` フォルダを GitHub Pages で公開すると、スマホなどからもブックマークして使えます。

1. GitHubリポジトリの Settings → Pages で、公開元を `main` ブランチの `/youtube-no-shorts` フォルダ（または任意のブランチ）に設定します。
2. 発行されたURLにアクセスし、初回のみAPIキーとチャンネルを設定します（設定はブラウザごとの保存なので、別端末では再度APIキー入力が必要です）。

ローカルで試す場合は `youtube-no-shorts` フォルダ内で以下のように簡易サーバーを立てて開いてください（`file://` で直接開いても動作しますが、環境によっては `fetch` がブロックされる場合があります）。

```bash
cd youtube-no-shorts
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 広告について

このサイト自体に広告は一切ありません。ただし動画再生には YouTube の埋め込みプレーヤーを使うため、動画自体に広告が挿入されている場合、埋め込みプレーヤー上にも広告が表示されることがあります。

**Brave ブラウザ**で開くと、標準搭載の「Brave Shields」がYouTubeの動画広告を含む大半の広告を自動的にブロックしてくれます。ブラウザのアドレスバー右のシールドアイコンが「有効」になっていることを確認してください（デフォルトで有効です）。Chrome など他のブラウザを使う場合は、uBlock Origin 等の広告ブロック拡張機能を別途インストールすることをおすすめします。

## 注意事項・制限

- YouTube Data API には「この動画はショートか」を直接返す項目が存在しないため、上記2モードはいずれも近似的な判定です。100%の精度を保証するものではありません。
- YouTube Data API の無料利用枠（1日10,000 quota）を超えると、その日はAPIエラーになります。検索(`search.list`)は1回あたり100 quotaと消費が大きいため、多用すると上限に達しやすい点にご注意ください。
- チャンネル登録数が多いほど、ホームフィード更新時のAPI呼び出し回数が増えます。
