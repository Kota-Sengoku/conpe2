No Shorts Tube ショート動画なしのYouTube

設定

APIキーはこの端末のブラウザ内(localStorage)にのみ保存され、外部には送信されません。 未取得の場合は Google Cloud Console で「YouTube Data API v3」を有効化し、APIキーを発行してください。

YouTube Data APIには「ショートかどうか」を直接返す項目がないため、この2通りの近似判定から選べます。 「動画の長さ」判定は60秒以下の動画のみ除外するため、60秒超のショートは残る場合があります。 「/shorts/ URL判定」はYouTube側の内部ページを1本ずつ確認するためより正確ですが、動画数が多いと時間がかかります。
