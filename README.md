# お金の記録（自分専用・家計簿PWA）

PayPayの利用明細とレシート写真をもとに、今月使ったお金をまとめる自分専用のWebアプリです。
サーバーは使わず、データはすべてこの端末のブラウザ内（IndexedDB）だけに保存されます。誰にも送信されません。

## 使い方

### 開く
ブラウザで `index.html` を開くだけで動きます（ローカルでもホスティングしてもOK）。
スマホでSafari/Chromeから開き、共有メニューの「ホーム画面に追加」を選ぶと、アプリのように使えます（PWA）。

ローカルで試す場合は簡易サーバーが必要です（`file://` だとService Workerが動きません）。
```
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

### 4つのタブ
- **入力**：手入力での追加 / レシート写真の自動OCR読み取り / PayPay CSVの一括取り込み
- **カレンダー**：写真のデザインを再現。日ごとの支出額、月の収入・支出・合計、取引一覧
- **グラフ**：カテゴリ別の内訳（円グラフ）と直近6か月の推移
- **設定**：毎月自動で追加されるサブスクの管理、バックアップの書き出し/読み込み、データ削除

### PayPayのデータを取り込む
PayPayには個人が使える公式APIがないため、完全自動でPayPayの口座から直接データを取得することはできません。
最も確実な方法は、PayPayアプリの「くらしのマネー管理」→ 利用履歴のCSVエクスポートを使うことです。

1. PayPayアプリでCSVをエクスポートする
2. このアプリの「入力」タブ → 「PayPayの利用明細CSVを取り込む」でファイルを選択
3. 日付・金額・内容の列を自動検出します（うまく検出できない場合は手動で列を選び直せます）
4. プレビューを確認して「一括取り込む」を押すと、まとめて登録されます

### レシート写真の自動OCR
「入力」タブでレシートを撮影/選択すると、ブラウザ内で完結するOCR（Tesseract.js）が動き、金額の候補を自動抽出します。
候補をタップして選ぶか、手で修正してから保存してください（OCRは完璧ではないため、必ず金額を確認することをおすすめします）。

### サブスクの自動追加
「設定」タブでサブスク（名前・金額・毎月の日にち）を登録すると、その月をカレンダーで開いたときに自動で取引として追加されます。

### データのバックアップ
「設定」タブの「バックアップを書き出す」でJSONファイルとして保存できます。機種変更時などは「バックアップを読み込む」で復元してください。

## 技術構成
- 素のHTML/CSS/JavaScript（ビルド不要）
- データ保存：IndexedDB（ブラウザ内、非公開）
- グラフ：Chart.js（CDN）
- OCR：Tesseract.js（CDN、処理はすべてブラウザ内で実行）
- PWA対応：`manifest.json` + `sw.js`（オフラインでもアプリ本体を表示可能。CDN読み込みにはネット接続が必要）

## 制限事項
- PayPayの自動ログイン等による完全自動取得は行っていません（非公式な手段は規約リスクがあるため未実装）。CSVエクスポート＋自動取込が最も安全で確実な方法です。
- OCRの読み取り精度はレシートの写真の状態によって変わります。必ず金額を確認してください。
- データは端末のブラウザに保存されるため、ブラウザのデータを消去すると記録も消えます。定期的にバックアップの書き出しをおすすめします。
